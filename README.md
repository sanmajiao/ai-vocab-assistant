# 词达人屏幕识别助手

面向微信「词达人」公众号单词页面的屏幕识别与翻译辅助工具。

将安卓手机投屏到 Windows 电脑，本地提取单词题目、选项、填空字母提示及长度，再通过 DeepSeek 官方 API 显示翻译候选。由使用者核对并手动选择或填写。此项目为独立工具，与微信、词达人及其运营方无隶属关系。

当前版本：**2026.10.12.5**。支持 Windows x64；目前提供电脑版，尚无 Android APK。

本地独立 OCR 还需要微软 Visual C++ x64 运行库。缺少 `MSVCP140.dll` 或引擎无法载入时，请从[微软官方页面](https://learn.microsoft.com/en-us/cpp/windows/latest-supported-vc-redist)获取 x64 安装包；不要从随机网站下载 DLL。开发机已有该运行库，其他电脑仍需确认。

## 功能

- 识别截图中的三/四选项，以及带中文释义、英文上下文、前缀和横杠长度的填空题。
- 选择投屏应用窗口，或按截图方式框选区域；预览程序实际读取的画面。
- 本地中英文 OCR，系统中文识别不可用时使用独立 RapidOCR 模型。
- 输入单词和输入法浮层出现时保留参考答案；连续确认新题后再更新。
- 手动重试重新截图、重新识别，可补充本题前缀和总字母数；未知长度可以留空。
- 电脑悬浮窗口显示候选，可拖动。程序不自动点击、输入或提交手机答案。

## 使用便携版

便携版将在 GitHub Releases 提供；首次发布准备中，当前尚无公开下载地址。

1. 完整解压到可写目录，勿在压缩包内直接运行。
2. 通过 scrcpy 或其他投屏软件显示手机画面。
3. 打开助手，在「DeepSeek API」页填写自己的官方 API Key，点击加密保存并测试连接。API 调用由自己的账户计费。
4. 选择投屏窗口并打开画面预览，确认看到当前手机题目。窗口不能最小化或被其他窗口遮挡。
5. 页面不同或区域不对时，使用「框选题目区域」，保留题干、全部选项或填空提示，确认范围后开始识别。
6. 核对「当前识别内容」和候选后操作手机。提示漏读时，填写原始前缀/总长并重读；不要把自己已输入的字母当作原题提示。

可先运行本地识别检查，不需要 API 密钥。自检通过但题目不对时，优先检查捕获预览；反复请求接口无法修复来源错误。

## 从源码运行

开发机验证环境：Windows、Python 3.13.12（含 Tk）。以下操作只针对本项目目录；投屏工具自行从[官方 scrcpy 项目](https://github.com/Genymobile/scrcpy)获取，或使用已有工具。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m pip install -r requirements-ocr.txt --target ocr_dependencies
.\.venv\Scripts\python.exe local_check.py
.\.venv\Scripts\pythonw.exe app.py
```

`ocr_dependencies` 包含识别组件及模型，不需要配置在线视觉 API。首次加载模型可能较慢。源代码安装的网络和包兼容性仍需在你的机器核对；现有验证基于开发机环境。

```powershell
# 无真实 API、无个人截图的解析/网络模拟和题目状态检查
.\.venv\Scripts\python.exe -m unittest test_unit test_state_v5 -v

# 原生窗口捕获与界面检查，需可交互的 Windows 桌面
.\.venv\Scripts\python.exe -m unittest test_capture_v5 -v
```

公开测试不包含开发时用户提供的私人截图，也不会读取已保存的 API 密钥。截图类历史检查未纳入公开测试集。

## 隐私与接口

- 截图在本机处理，发送到 DeepSeek 的是提取的题目文字、选项和提示，图片不上传。
- 每次请求只含系统提示和当前题目，历史聊天为零轮。本地题目状态和答案缓存不等于模型对话上下文。
- 密钥通过 Windows DPAPI 加密，绑定当前 Windows 用户。复制到另一台电脑后需填写自己的密钥。
- 程序会在 `data` 保存设置、答案缓存和最近读取的截图/诊断；这些可能含个人题目内容。分享时使用原始发布包，勿重新压缩已使用的目录。
- 反馈问题前，请遮盖密钥、账号及其他个人信息，勿提交整个 `data` 目录。

## 准确性与已知限制

识别和答案都需要人工核对。自动检查主要验证选项对应、格式、已确认前缀与长度，不能证明词义符合某一词库的唯一标准答案。

开发时 64 项检查通过，含用户提供截图、输入状态回放、原生窗口捕获和独立 OCR。7 个样本的真实 API 请求含 OCR 耗时约 1.56–2.41 秒。这些是开发机样本结果，不能当作全部手机、所有投屏软件或其他电脑的验收。

完全遮挡中文、特殊字体、复杂多行或横排布局仍可能无法读取。同义词可能同时满足提示；当前未内置完整标准词库。缺提示时答案会标为候选，换题未确认时显示上一题参考。

识别完成后的接口等待预算为选择题 5 秒、填空题 10 秒；总耗时还包括本地识别和确认，不等于手机剩余时间，也不保证每次在时限内完成。

## 开发结构

| 文件 | 用途 |
|---|---|
| `app.py` | 主界面、框选、预览与悬浮候选 |
| `windows.py` | 可见窗口捕获、来源校验与 DPAPI |
| `ocr.py` / `ocr_worker.ps1` | 系统 OCR 与独立识别引擎 |
| `reader.py` / `core.py` | 题目提取、提示识别和答案校验 |
| `pipeline.py` | 换题确认、输入保护、重试和过时结果隔离 |
| `network.py` | DeepSeek 官方接口 |
