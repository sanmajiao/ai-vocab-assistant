# Android 词汇助手 0.1.7-preview

[下载 APK 与分享包](https://github.com/sanmajiao/ai-vocab-assistant/releases/tag/v0.1.7-preview)。Android 8.0 及以上，独立安装，不需要电脑或投屏软件。项目与微信、词达人及其运营方无隶属关系。

**识别和答案正确率无法保证 100%。** OCR 可能漏读或误读，词义、搭配和题库答案可能存在歧义，模型也可能给出错误候选。请核对题干、全部选项、候选及顺序后自行作答；本工具不自动点击、输入或提交。

## 使用步骤

1. 安装 APK，打开“词汇翻译助手”。首页顶部是“开启悬浮助手”；首次使用展开下方 DeepSeek API 配置，填写自己的官方 API Key 并保存。默认模型 deepseek-flash，调用由自己的账户计费。
2. 阅读“屏幕防护与手机品牌指南”。有共享防护时，按手机提供的设置解除题目画面的模糊/打码。原图仍被遮住、系统或应用不允许解除时，请停止使用；本产品不能恢复被遮住的内容。
3. 开启悬浮助手，允许悬浮窗与屏幕共享，返回完整题目，点击“已切换·识别”。换题须再次点击；“重试”会重新读取画面。
4. 核对候选后自行选择或填写。浮窗可拖动、收起、滚动查看完整答案、复制或关闭，最多占屏幕三分之一。未重新识别时显示的是上次结果。
5. 填空提示漏读时，可在首页补中文释义、原始前缀或单词总长度，仅用于下一次手动识别。不要把正在输入的答案当成原始提示。
6. 排查时展开“开发者选项”，开启开发者模式及“保存本次截图与 OCR 诊断”，重新识别后查看本次原图和日志。诊断默认关闭，关闭任一开关即清除缓存。
7. 开发者模式下打开“按题型编辑提示词”，选择单选、多选、排序或填空。保存后下一次识别生效，可恢复当前默认；切换题型保留草稿，返回提醒未保存内容。关闭开发者模式会停用自定义，但保留内容。输出格式由应用固定维护。
8. 使用结束停止助手，并恢复临时关闭的可选防护。锁屏、系统撤销共享或杀进程后需重新授权。

## 功能与本次更新

- 普通中英互译、句中划线词语境义、搭配多选、词块排序和单词填空；题型在本机判断，只发送对应说明与必要字段。
- 排序支持 one's、智能撇号、缩写及连字符词块。接口只返回排好顺序的原词块，手机统一生成序号；校验词块来源、数量及可用次数，不把干扰项强塞入答案。
- 可见四个选项卡但漏读时，本机补读选项区域；仍不完整则提示重试，不把剩余三项压缩编号。
- 首页突出启动入口，API 与隐私折叠；青绿、靛蓝与暖白界面。[界面参考](UI_REFERENCES.md) · [待修复记录](KNOWN_ISSUES.md)。

## 隐私、许可与限制

截图和 OCR 在本机处理，图片不上传至 DeepSeek；每次仅发送当前题目文字与提示，无历史聊天。密钥经 Android Keystore 加密保存，设置和编辑页禁止截屏。卸载会清除设置；覆盖更新的 Key 保留需按设备核对。

默认不保存截图或 OCR 诊断。主动开启开发者与诊断后，只在私有缓存保留最近一次截图和文字。排序接口诊断仅记录协议字段类型/数量及校验类别，不记录响应正文或 Key；关闭清除。分享前自行核对日志与截图内容。

APK 集成 Google ML Kit 中英文模型及运行依赖。ML Kit SDK 可能请求更新及发送性能/使用指标；来源、条款和组件通知见 [第三方说明](THIRD_PARTY.md) 与 APK assets。没有捆绑 scrcpy、Python 或其他独立应用。

GitHub 发布的是开发签名预览 APK，不是商店正式版本。相同包名与签名支持覆盖安装。146 项本地测试通过，lint 0 错误、18 警告；这些验证结构与固定输入，不能保证真实题库准确率或所有设备兼容性。用户已进行手动实测，仍可能出现题义判断、排序、低对比文字及网络错误。不要把测试通过当成 100% 正确率保证。

## 从源码构建

需要 JDK 17、Android SDK 35、Build Tools 35.0.0。Gradle Wrapper 使用 8.11.1，分发校验值已写入配置。在 android 目录运行：

```powershell
.\gradlew.bat testDebugUnitTest assembleDebug lintDebug
```

Linux/macOS 使用 `./gradlew testDebugUnitTest assembleDebug lintDebug`。输出为 app/build/outputs/apk/debug/app-debug.apk。自行构建会生成自己的开发签名，与这里发布的签名不同。不要提交 Key、Keystore、local.properties、个人截图、缓存或构建输出。
