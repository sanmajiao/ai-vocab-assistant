# 界面参考与本轮设计

本轮查阅公开产品画面与设计说明，使用自绘颜色、形状和布局，没有复制第三方图标、插画或界面素材，没有增加界面依赖。

- [Google Material 3 Expressive 设计研究](https://design.google/library/expressive-material-design-google-research)：参考通过颜色与形状突出主要操作的层级。
- [Google Material 产品设计与案例](https://design.google/library/making-more-with-material)：参考圆角容器、字体层次与主题色。
- [Duolingo 首页设计说明与画面](https://blog.duolingo.com/new-duolingo-home-screen-design/)及[新版核心页面画面](https://blog.duolingo.com/core-tabs-redesign/)：参考首页清楚的下一步入口。
- [Forest 官方应用画面](https://www.forestapp.cc/)：参考平静的绿色配色和显眼的启动操作。

应用采用暖白背景、青绿主按钮、靛蓝状态与圆角卡片。首页先显示开启悬浮助手与使用步骤，API设置后移并折叠；隐私说明和开发者选项折叠。开发者模式与诊断记录均默认关闭。浮窗最多占屏幕三分之一，结果可滚动，换题后仍需主动点击识别。

本机未连接手机或模拟器。源码、构建和静态检查不能代替实际字体、屏幕尺寸、触控与系统权限界面的验收。
